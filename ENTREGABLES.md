### commit.sh
```
Qué hace:
• Lee mensaje de commit
• Valida cambios: git status
• Pregunta antes de commitear (confirmación)
• Hace git add -A
• Hace git commit
• Muestra resultado
• Da instrucciones de push

Uso: chmod +x commit.sh && ./commit.sh
Ahorra: 2 minutos por commit
```
