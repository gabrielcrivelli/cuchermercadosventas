# Consolidador de Ventas Mensuales - Cucher Mercados

Herramienta web para consolidar ventas retail desde múltiples archivos Excel.

## Funcionalidades

- Consolidación de ventas por producto, mes y sucursal
- Ranking de productos más vendidos
- Análisis por sucursal y departamento
- Evolución mensual
- Categorías especiales con filtros
- Análisis de estacionalidad (índice estacional por producto)

## Uso

Subí tus archivos Excel con el formato: `N. MES AÑO SUCURSAL.xlsx`  
Ejemplo: `3. MARZO 2025 CORRIENTES.xlsx`
